# ManboShot 桌面宠物系统

## 目标

桌面宠物只订阅翻译流程状态，不依赖具体 AI 服务、Google 接口或 OCR 实现。角色资源与业务代码分离，使内置角色、用户角色和后续复刻角色都能使用同一套交互。

## 状态映射

| 业务事件 | 宠物状态 | 气泡行为 |
| --- | --- | --- |
| 无任务 | `idle` | 隐藏 |
| 开始截图 OCR | `ocr` | 显示“正在识别截图” |
| 发起翻译或仍有引擎加载 | `translating` | 显示原文摘要和进度 |
| 至少一个引擎成功且全部结束 | `success` | 显示主要译文 |
| 一个引擎失败、另一个成功 | `partial_error` | 显示可用译文和轻提示 |
| 所有可用引擎失败 | `error` | 显示失败说明和打开主窗口入口 |
| TTS 播放中 | `speaking` | 保留当前译文 |

同一翻译任务的流式回传只更新内容，不重新创建宠物窗口。完成状态在短暂动作后回到待机，结果气泡按超时自动收起。

## 宠物包

内置宠物位于 `assets/pets/<id>/`，用户宠物位于 `%APPDATA%/MaoboShot/pets/<id>/`。用户目录中的同名 ID 优先。

每个目录至少包含：

- `pet.json`：角色名称、版本、画布、主图和动作参数。
- 主图文件：PNG 或 WebP，推荐透明背景和完整角色轮廓。

运行时只读取包内相对路径，并校验资源不能越出宠物目录。当前 schema 为 `1`；角色可使用单图变换、`rig` 分层活动区域，也可通过 `animations` 声明逐帧动作。每个动作提供帧路径、逐帧时长、参考高度和共享基线，所有资源都必须位于宠物包目录内。

## 可复刻规范

- 基准画布为 `192 x 208`，角色始终保持完整轮廓。
- 固定 3 到 5 个身份锚点，例如额头花纹、耳形、尾纹和配饰。
- 限制颜色与细碎配件，保证不同动作中的一致性。
- 所有角色实现相同状态名；动作幅度由包内 `motion_presets` 调整。
- 可选的 `rig` 描述眼睛、尾巴和前爪等活动区域。运行时会把这些区域拆成独立图层，因此眨眼、摆尾和挥爪不是整图位移。
- `animations` 用于完整姿势变化。狸花猫的 `lick_paw` 使用 8 张 `192×208` 透明帧；首尾由已确认的待机原画绘制，避免动作结束时发生体型跳变。
- 透明背景为正式资源首选；首版狸花猫素材支持浅色背景自动抠取，便于后续无损替换成正式透明精灵图。

## 窗口与多屏

宠物使用独立透明置顶工具窗口。位置使用 Qt 的全局逻辑坐标保存，支持负坐标副屏；启动、拖动结束和屏幕变化时都按当前屏幕可用区域约束。大小可在 `70%–140%` 间调整，缩放后会重新计算边界。双击宠物打开主翻译窗口，右键可触发舔爪、眨眼或跳跃，也可隐藏气泡、打开设置或隐藏宠物。
